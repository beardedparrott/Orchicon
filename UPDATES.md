(4) The Providers tab auto-saved hidden-models per checkbox click — visibility is now staged with an explicit Save/Discard pair (single update, ADR-0006 D4 operator flow). Session lifecycle: proactive refresh was armed only on interactive login, so every full page load drifted to a dead 15-minute access token and mutations surfaced raw `ConnectError: [unauthenticated]` — the bootstrap path now arms the proactive refresh (refresh-bootstrap and token-verify), and a definitively dead session clears the token/session store and lands on /login?next=… instead of an inline error string.
